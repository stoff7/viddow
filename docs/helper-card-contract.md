# Компактная панель Viddow

12 ноября 2026. Реализация плана `handoff/helper-ui-plan.md`.

- Ключ карточки плеера — существующий mediaKey (вкладка, документ, frame,
  media ID, generation). Сетевые адреса без доказанной связи остаются в деталях.
  Результаты партии без однозначного плеера имеют отдельный source_id; картинки
  соседних плееров к ним не подставляются.
- Анализатор остаётся один на native-сеанс. Автоподготовка сохраняет существующий
  лимит; при нескольких плеерах сначала нужен явный выбор. Выбор другого плеера
  отменяет прежнее намерение. Загрузка начинается только по нажатию.
  Нажатие превью выбирает и готовит видео без загрузки; «Скачать» во время
  подготовки сохраняет раннее намерение. Готовые форматы доступны для текущего
  анализа; после подготовки другого плеера прежнее видео нужно подготовить снова.
- Селекты принадлежат карточке и текущему analysis_id/source_id. Новый анализ
  инвалидирует прежние форматы; DOM карточки на progress не пересоздаётся.
  Несколько аудиодорожек доступны через раскрываемый выбор с checkbox.
- Связь job ID с карточкой сохраняется background в storage.session вместе с
  native session. Повтор наследует связь; attempt_id остаётся у native-host.
  Активные задания и успехи не заменяются ошибками связанной попытки.
- После исчезновения плеера/смены вкладки задания доступны через общую очередь.
  После закрытия/открытия панели связь восстанавливается в том же сеансе браузера.
  Новый native-сеанс не наследует привязку ID старого сеанса.
- Только done означает успех. Reveal доступен по клику при наличии пути,
  файла и подключения. Восстановленная история не объявляется новым событием.
  Фоновые завершения обозначаются счётчиком в нижней навигации «Загрузки».
- Без новых разрешений, runtime-зависимостей, таймеров опроса, расширения партий,
  изменений frame cache, observer и извлечения дорожек.

Приёмка: 320/400 px, обе темы, клавиатура; три плеера и 30 видео; раннее нажатие,
отмена, смена плеера/страницы/сеанса; очередь → progress → done/error/cancelled;
повтор attempt, offline, удалённый файл, restored, закрытие и открытие панели.
Прогоны не выполнены: действует ограничение «без тестов» из handoff.
