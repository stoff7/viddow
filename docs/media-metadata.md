# Получение данных видео до переработки карточки

**Статус: проект контракта, не реализован в рабочем расширении.** Начатый
эксперимент сохранён в [patch](../handoff/experiments/media-metadata-2026-11-12.patch)
и не подключён к приложению. Проверенные выводы и результаты сессии:
[session-report-2026-11-12.md](session-report-2026-11-12.md).

Сначала улучшаем данные, текущую компоновку сохраняем. Основа — данные самого
плеера и результата анализа; общий постер страницы не становится обложкой серии.

Проверенная структура страницы пользователя: yummyanime.tv → видимый iframe
controller.php → thealloha.club. Второй iframe controller.php → Kodik скрыт.
В верхнем документе нет video, а og:image содержит общий постер аниме. Простого
чтения верхней страницы или выбора первого video во всех фреймах недостаточно.

## Контракт

- Читаем доступные документы через scripting и дерево фреймов webNavigation.
  Скрытый предок исключает плеер. Неоднозначные фреймы/несколько видео не
  объединяются. Поздние результаты старого документа отбрасываются.
- Изображение: poster выбранного video → thumbnail соответствующего VideoObject
  → кадр уже декодированного video → изображение страницы. У каждого результата
  остаётся источник. Кадр берётся без play/seek, только из уже показанного видео;
  ограничен 320×180 и 128 КиБ, JPEG. Canvas с запретом CORS пропускается.
- Длительность: video.duration → соответствующий VideoObject.duration → явные
  video-метаданные. Отдельно отмечаются live и отсутствие значения. Размер
  плеера в CSS не используется как разрешение файла.
- JSON-LD читается с ограничениями размера/числа/глубины. Несколько VideoObject
  требуют точного соответствия contentUrl/embedUrl выбранному media URL.
- После анализа преимущество имеют метаданные извлекателя. Если он не вернул
  изображение/длительность, сохраняем сведения того же выбранного источника.
  Смена вкладки или media URL не подставляет новый кадр в старый выбор.
- Эти данные живут в памяти панели, не записываются в историю/журнал. URL,
  cookies, заголовки и пиксели видео в диагностику не попадают.
- Новое разрешение webNavigation используется для чтения дерева iframe.
  Без доступа к документу сведения остаются неизвестными; запреты не обходятся.

Короткое видео-превью с отдельным скачиванием фрагментов — другой механизм;
сейчас его не добавляем. Здесь получаем изображение и метаданные для будущей
карточки, не начинаем загрузку ролика и не меняем качество автоматически.
