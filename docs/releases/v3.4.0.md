# Viddow v3.4.0

12 ноября 2026.

## Изменения

- Компактная панель с отдельными карточками видео, превью/длительностью,
  качеством, несколькими звуковыми дорожками и одним главным действием.
- Очередь, прогресс, отмена, повтор и «Показать файл» внутри карточки.
  Технические действия перенесены в ⋯, навигация — вниз; завершения отмечаются ✓.
- Связи карточек с заданиями хранятся в сеансе расширения и наследуются при
  повторе. Общая очередь и история доступны для всех вкладок.
- Неизвестные отдельные HLS-дорожки проверяются ffprobe. Видео и звук X
  объединяются только при совпадении точного media ID; настройки каждой дорожки
  передаются через частный временный info-json с правами 0600.
- Только звук и неизвестный состав дорожек не запускают автоматическое
  скачивание под видом видео. Явный выбор формата сохранён.
- GIF уменьшены до 160×90, восьми кадров и двух секунд с проверкой размера
  окончательного data URL. Обходы плееров объединяются, кадры кешируются.
- Защита от повторяющихся ошибок после потери контекста расширения.

## Установка и обновление

Скачайте `viddow-3.4.0.zip`, распакуйте в постоянную папку. На macOS установите
Python 3.9+, yt-dlp и ffmpeg (`brew install python yt-dlp ffmpeg`). Загрузите папку
`extension` как распакованное расширение Chromium и выполните из папки проекта
`python3 install_native_host.py`. Подробности — в README.

При обновлении сохраните прежний путь проекта. Дождитесь завершения загрузок,
обновите файлы, перезагрузите расширение и страницу с видео. Если путь изменился,
загрузите расширение заново и повторите регистрацию native-host.

## Границы проверки

Новая панель сверена по исходному коду. По сохранённому указанию пользователя
тесты, syntax-check и браузерные прогоны после UI-изменений не выполнялись.
Сценарии 320/400 px, клавиатура, темы, несколько плееров, раннее нажатие,
смена вкладки/сеанса, восстановление панели и reveal требуют проверки.
Существующие browser smoke-скрипты используют прежний интерфейс и требуют
актуализации перед запуском. Старые зелёные результаты не подтверждают этот UI.

Анализатор остаётся один на native-сеанс: подготовка другого видео инвалидирует
прежние форматы. Поддержка сайтов зависит от установленного yt-dlp и доступа
к источнику. Установщик и показ файла рассчитаны на macOS.
