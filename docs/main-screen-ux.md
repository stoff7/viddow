# Главный экран и выбор качества

Исправление запуска с сохранённой историей и журнал панели:
[extension-diagnostics.md](extension-diagnostics.md).

## Границы и инварианты

Основной путь: текущая страница → подготовка → качество и звук в той же
карточке → явное скачивание. Название вкладки подписано как страница; название
видео и обложка появляются только из метаданных. Подготовка не создаёт загрузку.
Палитра, backend, Native Messaging, история и очередь сохраняются. Новых
зависимостей и объединения разных потоков не добавляем.

Результат привязан к ID анализа и его URL, а не к активной вкладке. При смене
вкладки выбранный источник остаётся подписан своим сайтом и адресом. Возврат к
текущей странице — явное действие. Смена сеанса сбрасывает устаревший выбор.

Предварительный выбор предпочитает вариант со звуком. Отдельное видео допустимо
выбрать со звуком автоматически только при единственной аудиодорожке и наличии
ffmpeg. При нескольких дорожках пользователь выбирает озвучку сам. Немое видео
требует явного согласия. Неизвестный состав обозначается явно; ID и технические
характеристики доступны в деталях. Порядок не называется гарантией качества.

Перехваченные потоки и ручная ссылка доступны в раскрываемых блоках. Полные
адреса, query, заголовки и существующие правила группировки сохраняются.
Скачивание без анализа доступно и при ошибке подготовки. После добавления
задачи раздел не переключается; в карточке видны состояние и ссылка на очередь.

## Ранние сведения и автоматическая подготовка

По уточнению пользователя подготовка запускается автоматически при наличии
плеера, video-метаданных страницы или перехваченных потоков. Только для текущей
страницы, один раз на URL/вкладку/сеанс/выбор браузера YouTube. Ошибки не вызывают
автоматических повторов. До появления видео доступен ручной запуск. Обнаруженные
потоки автоматически не выбираются: анализируется исходная страница.

Открытый выбор сохраняется при смене вкладки. Кнопка возврата к текущей вкладке
разрешает подготовку нового источника. Общий background защищает автозапросы от
дублей между панелями и проверяет ожидаемый ID анализа перед запуском. Скачивание
всегда требует отдельного подтверждения, автоматический анализ не меняет раздел
и не переносит клавиатурный фокус.

До окончания анализа читаем `video.poster`, реальную `video.duration` и явно
опубликованные video-метаданные. Общее `og:image` подписывается как изображение
страницы, а не подтверждённая обложка видео. Несколько неоднозначных плееров не
объединяются. Live/неизвестная длительность не превращаются в ноль. Смена
вкладки/URL отбрасывает поздний результат чтения. Данные не пишутся в историю.

Для чтения DOM активной страницы добавлено разрешение `scripting`; уже имеющийся
доступ к HTTP(S)-сайтам сохранён. Скрипт внедряется только по запросу открытой
панели, читает DOM в isolated world и реагирует на изменения метаданных. Нет
постоянного опроса, автоматического проигрывания или запросов манифестов ради
предварительного превью. Изображение загружается браузером без Referer. В
запрещённых/закрытых вкладках чтение безопасно пропускается. Анализ через native
host по-прежнему выполняет сетевые запросы в режиме simulate.

## Приёмка

- Подготовка, отмена, ошибка, пустой результат и отключение помощника объясняют
  состояние и следующий шаг. У недоступного основного действия есть причина.
- Выбор не теряется от обновлений очереди, смены вкладки и открытия разделов.
  Поздний анализ не подписывается названием новой вкладки.
- Точный выбранный формат/звук передаётся существующей командой. Нет молчаливого
  выбора немого видео или обещания всех озвучек.
- Прямой URL и поток без метаданных можно скачать. Очередь, cancel/retry и
  история продолжают работать; автоматического перехода в очередь нет.
- Проверить 320 и 400 px, обе темы, длинный текст, фокус и отсутствие
  горизонтальной прокрутки. Использовать точечные проверки, без полного прогона.
