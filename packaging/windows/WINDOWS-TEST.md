# Viddow для личной проверки: Windows 11 x64

Версия 3.5.0-test.1, неподписанная тестовая сборка. Python, yt-dlp,
FFmpeg/ffprobe и Deno входят в установщик. Дополнительные инструменты и PATH
не нужны. Пакет не устанавливает расширение автоматически.

1. Распакуйте Viddow-extension.zip в постоянную папку.
2. В Chrome откройте chrome://extensions, включите режим разработчика,
   выберите «Загрузить распакованное расширение» и эту папку. Для Edge —
   edge://extensions. Скопируйте ID расширения (32 буквы a–p).
3. Запустите Viddow-Setup-3.5.0-test.1-windows-x64.exe обычным пользователем.
   Введите ID для нужного браузера. Для второго браузера можно ввести другой ID.
   Пустое поле не меняет регистрацию этого браузера. При конфликте со старым
   помощником удалите его регистрацию его собственным средством.
4. Откройте панель расширения и проверьте подключение. Успешная установка файлов
   ещё не подтверждает подключение браузера.
5. Скачайте короткое видео, доступное вам: прямой MP4, затем HLS и источник
   с отдельными видео/аудиодорожками. Проверьте звук, длительность и «Показать файл».
6. Отмените загрузку. Проверьте отсутствие оставшихся yt-dlp/ffmpeg/ffprobe
   в диспетчере задач. Повторите с закрытием браузера. После перезапуска история
   должна сохраниться без самопроизвольной загрузки.
7. Проверьте папку с кириллицей и пробелами; стандартная Downloads определяется
   системным Known Folder, включая перенесённую папку.

Восстановление: завершите загрузки, закройте Chrome/Edge и запустите тот же
установщик с прежними ID. Данные загрузок не удаляются. Первая тестовая версия
не имеет автоматического обновления. Не обновляйте её во время загрузки.

Удаление: «Параметры → Приложения → Установленные приложения → Viddow (Windows test)».
Скачанные видео, история в расширении и журналы сохраняются. Расширение удаляется
отдельно. Журналы: `%LOCALAPPDATA%\Viddow\logs`, также доступны из меню «Пуск».
При ошибке установки прочитайте `installer-error.txt` в этой папке.
Для обращения приложите версию и обезличенный `viddow.jsonl`; не присылайте cookies
или ссылки с токенами.

SHA256SUMS.txt содержит контрольные суммы файлов комплекта. Установщик не подписан:
SmartScreen может показать предупреждение. Не отключайте защиту Windows.

Ограничения: Windows resume выключен; работа внешних CDN, cookies браузера,
сетевых и внешних дисков требует отдельной проверки. Публичного релиза нет.
Список проверок CI и ограничения — в отчёте, приложенном к комплекту.
