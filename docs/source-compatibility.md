# Этап 6: совместимость и оставшиеся ограничения

Приоритет пользователя: YouTube, X, VK и AnimeGo. Телефонная версия явно
отложена; Android/iOS в эту реализацию не входят. Основной UI — sidePanel.

## План и инварианты

- Проверенная матрица, без обещания «скачивает любой сайт». Локальный offline-набор:
  MP4, HLS, DASH, страница, iframe, Cookie/Referer, redirect/SPA.
- Полные URL/query/заголовки текущей загрузки сохраняются. Ни токены, ни активные
  задачи не отбрасываются ради лимита Native Messaging.
- Большие логические сообщения делятся на упорядоченные фрагменты в обе стороны;
  каждое wire-сообщение меньше 1 МиБ. Сборка ограничена по размеру и проверяет
  порядок/размер; отключение отбрасывает незаконченный транспортный буфер.
- Старый ответ запроса/документа не появляется после навигации/SPA-перехода.
- Отдельный звук разрешён также для combined-формата: встроенный звук остаётся,
  пользователь явно добавляет дополнительные дорожки. Требуется ffmpeg.
- Повтор транспортной команды после потерянного reply использует тот же
  request_id и не создаёт вторую задачу в живой сессии. После перезапуска нет
  автоматической отправки прежних команд; история остаётся источником проверки.
- Ошибки разделяют зависимость, сеть, отказ/вход, истёкшую ссылку,
  неподдерживаемый источник, DRM и недоступную папку. Сырые детали не пишутся
  в постоянную историю.
- Реальные внешние пробы выполняются отдельно от обязательных offline-тестов.
  В тестах нет пользовательского профиля/куки; Finder не открывается.
- Vivaldi проверяется только в отдельном временном профиле. Поддержку другого
  браузера/ОС не объявлять по наличию строки в установщике.
