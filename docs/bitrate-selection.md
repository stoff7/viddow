# Битрейт и выбор форматов

14 ноября 2026. Метаданные yt-dlp: vbr/abr/tbr в кбит/с; только конечные
положительные числа. Общий tbr combined-потока подписан «всего» и не выдаётся
за видеобитрейт. Неизвестные значения не вычисляются из названий или ID.

Ограниченный существующий ffprobe для одного потокового формата дополняет
недостающие vbr/abr из stream.bit_rate (бит/с → кбит/с). Бюджет остаётся 3 с,
probesize 1 МиБ, analyzeduration 1 с; это параметры анализа, не обещание точного
лимита сетевого трафика. Известные кодеки и битрейты сохраняются. Несколько
форматов не запускают пачку probes. Анализ сегментов для оценки не добавлен.

Выбор сохраняет звук: среди пригодных вариантов разрешение, FPS, затем битрейт
внутри одного кодека. Между кодеками сохраняется порядок первого появления,
а не утверждение, что больший битрейт означает лучшее качество любого кодека.

Для одного подтверждённого X media ID варианты аудио получают audio_group по
языку, каналам и кодеку. Все варианты остаются доступны. Если группа одна,
автоматически выбирается один вариант с максимальным abr (tbr для audio-only
как запасной источник). При разных группах нужен явный выбор. Для чужих сайтов
отсутствие языка само по себе не доказывает одинаковый звук. Ручные выборы
пользователя не сбрасываются обновлениями прогресса.

UI показывает кодек, битрейт, каналы; раздел называется «Звук». Новых зависимостей
и сетевых запросов в расширении нет. Изменения входят в Windows test.3;
локальный Python-host и extension используют новый код после перезапуска.

Проверки: `node --test tests/test_*.mjs tests/test_page_preview.cjs` — 59/59;
Python test_media_tracks/test_tracks_offline/test_inspector/test_native_session —
30/30, включая реальный offline mux и preview. git diff --check PASS.
Реальный X и визуальная проверка длинных подписей в браузере не выполнялись.

H.264/h264/AVC/avc1/avc3 (включая профиль RFC 6381) сравниваются как одно
семейство в UI и Python. Исходное имя сохраняется для диагностики.
При одинаковых разрешении/FPS 5,36 Мбит/с предпочитается 2,92 Мбит/с
независимо от порядка форматов. Другие кодеки этим правилом не объединяются.
