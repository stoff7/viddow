    ПАРА ПРОСТЫХ ШАГОВ

    Ссылка. Клик. Готово.

    1. Скопируйте ссылку

      На страницу с видео, файл или поток. Вставьте её в поле на главном экране.

    2. Нажмите «Скачать»

      Загрузчик выберет способ автоматически. Остальные задачи подождут своей очереди.

    3. Откройте папку сохранения

      Готовый файл останется на компьютере. Путь можно скопировать из карточки загрузки.

    История отображается до перезапуска сервера. Очистка списка не удаляет скачанные файлы.
    Расширение и диагностика

    Для перехвата потоков установите папку extension как распакованное расширение Chromium и выполните python3 install_native_host.py на macOS.

    Проверяем инструменты…

    Для страниц нужен yt-dlp, для объединения дорожек — ffmpeg. Установка на macOS: brew install yt-dlp ffmpeg.

    Поддержка зависит от источника. Если автоматическое определение не сработало, выберите «Страница с видео» в параметрах загрузки.
