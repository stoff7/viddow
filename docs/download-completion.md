# Явное завершение скачивания

12 ноября 2026. Актуальный интерфейс — компактные карточки по
[контракту панели](helper-card-contract.md). Это заменяет прежние два закреплённых
блока текущей загрузки и успеха над разделами.

- Подготовка, очередь и сохранённый файл различаются в одной карточке видео.
  Только job.status=done означает «Скачано». Ack не объявляется успехом.
- Основная кнопка меняется с «Скачать» на «Отменить», затем «Показать файл».
  Обновления progress не заменяют DOM карточки и её основную кнопку.
- Видны реальный progress, короткая ошибка, явная отмена и повтор. Несколько
  действительных задач/успешных файлов сохраняются внутри карточки, ошибки
  связанного attempt группируются существующим downloadCards.
- Реальное имя/путь результата и техническая причина доступны в ⋯. Полная
  очередь всех вкладок, включая исчезнувшие со страницы видео, — в «Загрузки».
- Reveal вызывается только по нажатию при подключении, наличии пути и файла.
  При file_exists=false виден статус «файл не найден»; Finder сам не открывается.
- Завершения вне открытого списка отмечаются ненавязчивым счётчиком ✓ у
  «Загрузок». Просмотр очереди сбрасывает счётчик. Фильтры очереди сохранены.
- Восстановленные restored-задания не объявляются новым завершением. Повторные
  снимки не объявляют тот же job заново. При открытии панели текущий native-сеанс
  даёт доступ к существующим задачам и результатам; ID проверяется вместе с session.
- Единственная область completionLive вежливо объявляет переходы и завершение.
  Фокус не переводится на прогресс или результат, нет системных уведомлений.

Modern Web Guidance: progress — «Announce completion without stealing focus»;
accessibility — «Centralize live regions for non-visible announcements».

В этой сессии проведена только сверка исходного кода. Тесты, syntax-check,
браузерные проверки и перезагрузка расширения не выполнялись: сохраняется
ограничение из handoff «без тестов». Прежние зелёные прогоны не подтверждают этот UI.
