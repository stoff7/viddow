## Прогресс первого этапа, 12 ноября

Идентичность DOM и точное сетевое сопоставление реализованы:
[контракт](../docs/media-identity.md), [проверки](../docs/media-identity-verification.md).
Прежние UX/диагностика сохранены отдельным коммитом `fb71a43`.
По уточнению пользователя картинка обязательна при множестве плееров: добавлены
визуальный выбор, декодированный кадр, poster fallback и локальная лента из 30 video.
Новый этап не доказывает поддержку настоящего X и связь blob/MSE с manifest.
Далее — этап 2 и перенос подтверждённых полей/картинок в результат анализа (этап 3).
Незавершённый эксперимент по-прежнему не подключён.

## Инварианты до начала изменений

- Выбор пользователя важнее фонового обнаружения. Автоматического скачивания нет.
- URL с query и необходимые заголовки не обрезаются; в журнал/историю не попадают.
- Не объединять источники по имени, домену или порядку обнаружения.
- Картинка необязательна: прямой файл и поток без метаданных всё ещё скачиваются.
- Веб-очередь и native-протокол не переписывать без необходимости.
- Новый код должен сохранять защиту смены сеанса, историю, очередь и startup fix.
- Экспериментальный patch читать как материал; не применять целиком без проверки.
- Для каждой стадии сначала обновить контракт и критерии, затем локальная правка
  и соответствующий тест. Не запускать весь набор после каждого изменения.

## 1. Идентичность и локальная фикстура — первый рабочий шаг

Затронуты: background.js, page-preview.js, popup.js, stream-model.mjs,
проект docs/media-metadata.md. По необходимости выделить маленькую чистую модель.

Определить общий ключ выбранного источника: tab, поколение документа/навигации,
frame, конкретное media. Сохранять доступные frameId/documentId сетевого запроса,
но не считать, что один фрейм равен одному видео. Учесть blob/MSE, редиректы,
отсутствие прямого соответствия currentSrc сетевому manifest и смену серии без
смены URL страницы. При недостатке свидетельств оставить кандидаты раздельными.

Добавить фикстуру: верхняя страница → видимый вложенный плеер и скрытый запасной;
отдельный порт для cross-origin; несколько video в одном документе; смена серии.
Определить, как устанавливается соответствие iframe-элемента браузерному фрейму:
одно дерево parentFrameId не доказывает видимость его DOM-контейнера.
Проверить необходимость webNavigation до добавления разрешения и описать её.

Приёмка: скрытый предок исключает кандидата, два видимых остаются неоднозначными;
поздний ответ старой серии/вкладки не меняет текущий выбор. Явный выбор сохраняется.

## 2. Метаданные потока вместо тупика на неподдерживаемой странице

Затронуты: автоматический анализ в popup/background, inspector.py и native_session.py
только при необходимости расширения существующего контракта.

Использовать существующий анализ yt-dlp для подтверждённого HLS/DASH. Не писать
второй полный загрузчик/парсер. Верхняя страница остаётся путём для поддерживаемых
сайтов; её ошибка не должна скрывать пригодный поток. При нескольких кандидатах
дать выбор, не назначать первый master автоматически. Определить условия одной
запасной попытки, ограничение запросов, дедупликацию панелей, отмену и таймаут.
Автоматическая отмена/ошибка не должны запускать бесконечные повторные анализы.

Приёмка: локальная неподдерживаемая страница с валидным HLS позволяет получить
качества без вставки CDN URL вручную; несколько кандидатов не смешиваются.
Две панели не дублируют анализ; пользовательская отмена останавливает цепочку.
Для реальной загрузочной проверки использовать валидные сегменты, а не прежнюю
конкурентную фикстуру с 404. Длительность/разрешение сверить с известной фикстурой.

## 3. Объединение данных и происхождение каждого поля

Для title, duration/live, poster, pageImage, frameImage, formats/audio/size хранить
источник и привязку к выбранному медиа. Определить приоритет отдельно для полей,
не заменять всю карточку объектом последнего ответа. Отсутствующее поле анализа
не стирает подтверждённое поле того же видео. Неизвестное не становится нулём.

DOM duration и JSON-LD допустимы при доказанном соответствии. JSON-LD ограничить
размером/числом/глубиной; несколько VideoObject требуют разрешения неоднозначности.
VOD-длительность можно получить из подходящего media-плейлиста при необходимости;
сумма окна live не равна длительности эфира, master сам длительность не гарантирует.
Размер DOM-плеера не является разрешением файла. Оценка размера не равна точному.

Приёмка: анализ без thumbnail сохраняет правильный постер; новая серия сбрасывает
старые данные; пустые, live, несколько VideoObject и поздние ответы проверены.

## 4. Кадр выбранного видео — отдельно от постера

Пересмотреть черновой приоритет poster → frame: общий постер не должен мешать
показать подтверждённый кадр серии. Хранить сущности раздельно, а правило выбора
изображения описать явно. Сначала пробовать уже декодированный кадр без play/seek;
при CORS/недоступном кадре использовать постер/заглушку, не ломая загрузку.
Лимиты из проекта контракта: 320×180, 128 КиБ, JPEG; проверить реальные размеры
сообщений, не передавать изображения с полным state всех задач через native-host.
Кадры не сохранять в истории/диагностике. Освобождать временные ресурсы.

Приёмка: пауза/пустой video/CORS/смена серии/скрытый плеер не дают чужую картинку;
снятие кадра не запускает воспроизведение и не меняет позицию. На реальном сайте
сравнить именно кадр серии, а не только атрибут poster. Отсутствие доступа честно
зафиксировать; не заявлять поддержку AnimeGo по наблюдению yummyanime.tv.
Отдельное скачивание короткого клипа как у конкурента пока не реализовывать.

## 5. Компактная карточка — после проверок данных

Небольшое превью слева, имя и длительность рядом, качество/озвучка рядом с кнопкой
«Скачать», прогресс в этой же карточке. Сохранить читаемые шрифты, текущую палитру,
ручной URL и технические подробности. Не переносить код/мелкие размеры конкурента.

Приёмка: на 320/400 px видны главный результат и следующее действие; длинные
названия, отсутствие изображения, несколько озвучек, ошибка и offline не ломают
раскладку. Клавиатурный фокус не прыгает от фоновых обновлений. Проверить обе темы.
