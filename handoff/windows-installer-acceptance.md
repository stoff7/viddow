## Чек-лист реального рабочего стола (всё пока открыто)

- Windows 11 x64: записать сборку ОС, версии Chrome/Edge и SHA-256 installer.
- По возможности чистая машина без Python/yt-dlp/FFmpeg. Если зависимости уже есть,
  явно указать это ограничение, проверить используемые комплектные пути.
- Распаковать extension в постоянную папку, загрузить через страницу расширений,
  скопировать реальный ID каждого браузера. Не ожидать автоматической установки.
- Завершить текущие загрузки и закрыть браузеры перед установкой. Обычный пользователь,
  per-user installer, свои IDs. Пустой ID не должен менять другой браузер.
- Настоящий connectNative из Chrome и Edge, корректное «Подключено», отсутствие
  мигающих console-окон. Registry success не равен browser connection success.
- Короткий прямой файл и HLS/video+audio: выбран именно нужный ролик, есть звук,
  длительность корректна, UI показывает настоящий результат сохранения.
- Отмена из панели и закрытие браузера: свои дочерние tools завершаются, очередь
  не висит, готовые файлы сохранены. Не завершать чужие tools по имени.
- После restart история сохранена, нет автозагрузки. Windows resume не обещается.
- «Показать файл» выделяет его в Explorer; кириллица/пробелы/перенесённая Downloads.
- Ошибки прав/места/отключённого диска проверять безопасной фикстурой, не заполнять
  настоящий системный диск ради теста. Не трогать пользовательские файлы.
- Repair и uninstall — после загрузок, без потери результата и чужой регистрации.
  Повторная установка той же версии проверена CI, multi-version upgrade — нет.

Заполнять результат каждой строки: PASS/FAIL/не проверено, среда, конкретный факт
и ссылка на обезличенный лог. Фраза «всё нормально» не заменяет результаты отдельных
сценариев, но не требует повторного прогона уже доказанного без причины.

## Диагностика

%LOCALAPPDATA%/Viddow/logs, installer-error.txt и viddow.jsonl; доступ из меню «Пуск».
Сперва читать доступные логи, не просить перепечатать весь экран. Не включать cookies,
заголовки, подписанные ссылки или личные пути в публикуемые отчёты. При необходимости
запросить только недостающие версию/код/обезличенный фрагмент. Не использовать личный
сеанс для автоматических тестов. Проверка внешних сайтов отдельна от локальной.
