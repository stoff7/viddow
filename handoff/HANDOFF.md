## Реализовано

- Постоянная sidePanel: «На странице», «Загрузки», «Настройки», ручная ссылка,
  текущая вкладка своего окна, темы, настройки папки/параллелизма.
- Один connectNative и JobManager всех вкладок/окон расширения. Закрытие панели
  сохраняет задачи; закрытие браузера останавливает хост и загрузчики.
- Session v2: ready/state/reply, request_id, проверка session ID на обеих сторонах,
  download/cancel/retry/clear/configure/reveal; одиночные команды совместимы.
- Очередь/отмена/очистка частичных файлов, yt-dlp/ffmpeg, общая валидация contracts.
- Полные URL/query/заголовки сохранены; одинаковый URL обновляет заголовки,
  группировка origin+pathname+kind, разные пути различаются, максимум 30 на вкладку.
- Этап 4 (расширение 3.1.0): «Качество и звук» для страницы/ссылки/потока,
  название, обложка/длительность при наличии, выбор разрешения и языков.
  `inspector.py` запускает отдельный ограниченный read-only yt-dlp анализ.
  `inspect`/`inspect_cancel`, `state.analysis`, выбор по analysis_id + format_ids.
  Источник/заголовки остаются в памяти хоста; задача получает неизменяемую копию.
- HLS master/media — по содержимому, включая пойманные адреса без расширения.
  Анализ не блокирует загрузки, отменяется/завершается по таймауту и EOF.
- Этап 5 (3.2.0): безопасная история в `chrome.storage.local`, version 1,
  миграция массива version 0, диагностика повреждения/ошибки записи и защита
  неизвестной будущей версии от перезаписи. Сырые CDN URL/заголовки/ошибки и
  старые format IDs не сохраняются; в памяти текущей задачи они остаются полными.
- Restore не запускает executor: активные записи становятся interrupted.
  Сохраняются даты, результаты, безопасная исходная страница, подпись формата,
  путь файла. Удалённый файл обозначен в UI. Очистка истории сохраняет файлы.
- `inspect_history` получает свежие форматы со страницы; загрузку пользователь
  подтверждает заново. Старые Cookies/Authorization/ID форматов не применяются.
- Хост объявляет `history_version: 1`. State публикуется перед reply, worker
  пытается сохранить безопасную проекцию до подтверждения UI.
- Веб-интерфейс и CLI сохранены. Веб-очередь самостоятельна и хранится в памяти.

## Исправления при завершении

- HTTP 413 проверяется по завышенному Content-Length без отправки тела в
  закрываемый сокет. Лимит сервера не менялся.
- Timeout вкладки вызван отсутствием UTF-8 в тестовой фикстуре, что подтверждено
  диагностикой активной вкладки. Проверка не отключена.
- Браузерные тесты используют настоящий SIDE_PANEL вместо обычной UI-вкладки.
- Повторно открытая панель больше не зависает на «Подключаем…» при готовом порте.
- Устаревшие session ID отвергаются хостом до изменения задач. Ошибки до ready,
  несовместимый протокол, таймаут и reconnect обработаны без автоповтора загрузок.
- Установщик получил `--user-data-dir` для изолированной регистрации в тестах.
