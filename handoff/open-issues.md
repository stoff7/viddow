## Остаточные вопросы и границы — вместе с этапом 6

По явной просьбе пользователя этот список не расширяет объём этапа 5.

- Ручной клик значка в toolbar пользовательского браузера и визуальный результат
  Finder ещё не проверены человеком. Автотест открывает настоящую панель жестом
  sidePanel.open; openPanelOnActionClick проверяется API. `open -R` выполнен успешно.
- Поддержка проверена на macOS с Google Chrome for Testing 156.0.8078.4.
  Другие Chromium-браузеры, Windows/Linux и внешние авторизованные сайты отдельно
  не проверялись. Не заявлять совместимость по одному наличию папки в установщике.
- Лимит Native Messaging — 1 МиБ на сообщение хоста. Большие сессии с длинными
  URL могут превысить его; разбиения state на части/пагинации ещё нет. Не заявлять
  поддержку таких очередей и не обрезать полные URL/токены ради размера.
- Редиректы/SPA и поздние ответы предыдущей навигации требуют отдельной проверки
  актуальности списка при долгой работе вкладки.
- Нет отдельной проверки нестандартных прав каталога/исчезновения диска.
  Невалидный путь валидируется; ошибка записи становится error задачи.
- Exactly-once после потери reply не гарантируется: таймаут предлагает проверить
  очередь; автоматического повторения команды нет.
- Этап 4 (качество/дорожки) реализован: [контракт и проверки](../docs/quality-selection.md).
  Внешние сайты/live/обложки зависят от metadata; внешняя совместимость не заявляется.
  Дополнительные аудиодорожки предлагаются только для video-only форматов.
- Этап 5 (постоянная безопасная история) завершён:
  [persistent-history.md](../docs/persistent-history.md). Веб-очередь по-прежнему
  самостоятельна и в памяти; автоматического продолжения частичных файлов нет.
- Матрица реальных источников и остальные текущие ограничения — этап 6.
- Finder не открывать в автоматических прогонах: по замечанию пользователя
  реальный reveal отключён по умолчанию (`VIDDOW_TEST_FINDER=1` только явно).
