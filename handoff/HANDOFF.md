## Состояние приложения

- Общая боковая панель Chromium, компактные карточки видео с качеством/аудио,
  прогрессом и результатом; native-host, очередь всех вкладок/окон, история.
- Выбранный плеер, автоматическая подготовка HLS/DASH, GIF, раннее намерение
  скачать, восстановление после ошибок страницы, группировка ошибок попытки.
- Подтверждение отдельных HLS-дорожек через ffprobe и объединение X video/audio.
- Web/CLI сохранены; веб-очередь отдельная. Не вводить daemon ради Windows.
- README описывает архив с Python-кодом; yt-dlp и ffmpeg ставятся отдельно.
  Удобный Windows-установщик с инструментами пока только предложение.

## Аудит Windows

- P1: Known Folder Downloads, два reveal, Windows device names, гонка финализации,

- macos_metadata.py уже защищён проверкой ОС. Очередь/EOF общие; менять их
  архитектуру ради Windows не требуется. Framework/daemon не вводить.
- В [аудите](windows-audit.md) сохранён контракт platform_support.py и ссылки
  на официальные Chrome/Edge/WinAPI. Launcher, Job Object и упаковка ещё не реализованы.
