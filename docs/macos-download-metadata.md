# Метаданные скачанного файла в macOS

11 ноября 2026, исправление в рамках этапа 6.

Пользователь получил предупреждение Apple при открытии MP4, скачанного из
Vivaldi. Проверка конкретного файла: контейнер MP4, H.264 1280×720, AAC,
обычные права 0644. Через NSURL его карантин определялся как
`LSQuarantineTypeSandboxed`, без сведений об обычной веб-загрузке.
Это наблюдение не является проверкой отсутствия вредоносного содержимого.

Native Messaging наследует контекст браузера, но запись через Python/ffmpeg/
yt-dlp не проходит оформление загрузки Chromium. `macos_metadata.py` после
успешного сохранения дополняет существующие свойства через публичный
`NSURLQuarantinePropertiesKey`, задаёт тип WebDownload и origin источника.
Используется системный osascript/JXA, сторонние зависимости не нужны.

Инварианты:

- Карантин не удаляется, системные флаги вручную не меняются, открытие не
  одобряется за пользователя. Настройки Gatekeeper и браузера не изменяются.
- Файлы без карантина сохраняют это состояние. Чужие файлы не обходятся.
- В метаданные передаются только origin без credentials/path/query/fragment;
  подписанные CDN URL и адреса просмотра не сохраняются.
- Оформляется завершённый файл, включая гонку успешного завершения и отмены.
  Ошибка оформления не превращает сохранённое видео в ошибку загрузки.
- На других ОС вызов пропускается. Таймаут системного вызова — 5 секунд.

Точечные проверки: временный файл с исходной меткой Vivaldi получает системный
идентификатор события; карантин остаётся, флаг user-approved не появляется,
байты не меняются. Файл без карантина остаётся без карантина. Настоящий путь
sidePanel → Native Messaging → MP4 прошёл с проверкой метки и побайтовым
сравнением. Открытие пользователем в IINA/Finder ещё требует ручной проверки:
исправление метаданных само по себе не гарантирует исчезновение предупреждения.

По просьбе пользователя тем же API оформлены метаданные уже скачанного
указанного MP4 в Downloads. Хеш содержимого до и после совпал; карантин сохранён.

Основание: [реализация Chromium](https://raw.githubusercontent.com/chromium/chromium/main/components/services/quarantine/quarantine_mac.mm),
[разъяснение Apple о типе Sandboxed](https://developer.apple.com/forums/thread/767612).
Используется тот же публичный API оформления; полный URL, который передаёт
Chromium, заменён на origin ради приватности.
