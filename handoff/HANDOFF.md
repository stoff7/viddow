## Что уже реализовано

- `download.py`: отмена HTTP/subprocess, остановка группы процессов POSIX,
  очистка частичных файлов, fallback страницы в yt-dlp, явный `source_kind=page`.
- `jobs.py`: общая реализация очереди, лимит, cancel/retry/clear и настройка в idle.
- Веб-интерфейс, HTTP API, тесты и спецификация первого этапа.
- `contracts.py`: общая проверка запросов; `native_session.py`: постоянный Native
  Messaging-сеанс с очередью всех вкладок расширения, командами и снимками состояния.
- Расширение 3.0.0: sidePanel, разделы «На странице», «Загрузки», «Настройки»,
  ручная ссылка, отмена/повтор, Finder, папка, параллелизм, темы.
- Группировка потоков по origin + pathname + kind. Полные URL и разные query
  сохранены, одинаковые имена в разных путях не склеиваются.
