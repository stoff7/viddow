  текущая вкладка своего окна, темы, настройки папки/параллелизма.
- Один connectNative и JobManager всех вкладок/окон расширения. Закрытие панели

  download/cancel/retry/clear/configure/reveal; одиночные команды совместимы.

  группировка origin+pathname+kind, разные пути различаются, максимум 30 на вкладку.
- Веб-интерфейс и CLI сохранены. Веб-очередь самостоятельна.

## Исправления при завершении

- HTTP 413 проверяется по завышенному Content-Length без отправки тела в
  закрываемый сокет. Лимит сервера не менялся.
- Timeout вкладки вызван отсутствием UTF-8 в тестовой фикстуре, что подтверждено
  диагностикой активной вкладки. Проверка не отключена.
- Браузерные тесты используют настоящий SIDE_PANEL вместо обычной UI-вкладки.
- Повторно открытая панель больше не зависает на «Подключаем…» при готовом порте.
- Устаревшие session ID отвергаются хостом до изменения задач. Ошибки до ready,
  несовместимый протокол, таймаут и reconnect обработаны без автоповтора загрузок.
- Установщик получил `--user-data-dir` для изолированной регистрации в тестах.
